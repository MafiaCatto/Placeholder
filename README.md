# TicketSmith

TicketSmith turns a rough software feature request into an engineer-ready plan:
acceptance criteria, implementation steps, test cases, risks, and a practical
estimate.

It runs entirely in the browser, stores only recent ticket titles on the local
device, and requires no API key, cloud account, or paid service.

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
```
